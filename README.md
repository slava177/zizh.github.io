# ziyi-zhang.com

Source for [ziyi-zhang.com](https://ziyi-zhang.com), built with Jekyll on the
[Academic Pages](https://github.com/academicpages/academicpages.github.io) template.
GitHub Actions (`.github/workflows/jekyll.yml`) builds and deploys the site on every push to `master`.

## Where things live

| What | File |
| --- | --- |
| Name, sidebar bio, profile links | `_config.yml` (`author:` block) |
| Home page | `_pages/about.md` |
| CV | `_pages/cv.md` |
| Publications | one file per paper in `_publications/`; `category:` is `conferences`, `manuscripts` (journals) or `preprints` |
| Top menu | `_data/navigation.yml` |
| PDFs and images | `files/`, `images/` |

## Run locally

Needs Ruby 3.3 (`brew install ruby@3.3`) and Node.js.

```bash
export PATH="/opt/homebrew/opt/ruby@3.3/bin:$PATH" LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8
bundle config set --local path vendor/bundle
bundle install
npm install
npm run build:js
bundle exec jekyll serve --livereload
```

Then open <http://localhost:4000>. `assets/js/main.min.js` is generated by `npm run build:js`
(CI builds it as well), so it is not committed; rerun that command after editing anything in `assets/js/`.
